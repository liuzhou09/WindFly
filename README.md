# WindFly

WindFly presents research code and flight-experiment data for UAV control under wind disturbances. Additional training resources will be added in future updates.

## Contents

- [`RA-Net/`](RA-Net/): residual acceleration model and evaluation figures.
- [`AW-Net/`](AW-Net/): wind-aware policy model and training entry point.
- [`experiment_data/`](experiment_data/): flight logs for trajectory-tracking and hovering experiments.

See the README in each directory for available code and data formats.
