# Flight experiment data

This directory contains raw recordings from two UAV flight experiments:

- [Prescribed Trajectory Tracking under Localized Turbulence](Prescribed_Trajectory_Tracking_under_Localized_Turbulence/): 48 flight logs for four controllers, three reference speeds, and four wind settings.
- [Precision Hovering Stabilization against Commercial Baselines](Precision_Hovering_Stabilization_against_Commercial_Baselines/): 12 motion-capture recordings from six comparison experiments.

Each experiment directory describes its file format and provides SHA-256 checksums.
